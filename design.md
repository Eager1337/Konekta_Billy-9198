# Konekta — website design

Public marketing website, web package only. No new API routes, database or marketplace backend.

## Identity
Approved palette: ink #101114, warm white #F7F7F2, one blue accent #2563EB. Muted #65666B; borders #DADBD5. Dark mode: ink background, warm-white text, muted #B6B7BC. Small text on dark uses white, not blue.
Manrope 800 display / Inter 400–600 body, self-hosted. Oversized tight headings, body 16–18px/1.6. Existing pin/person/K logo flattened to blue; no green or gradients.

## Layout
Editorial split hero, giant left headline, blue final line, right local shop portrait, location caption. Max-width 1360px, desktop gutters 56px, mobile 24px. Rectangular photography, divider-led sections and restrained 2–8px radii. No glow or decorative card grids.
Sections: hero; utility strip; interactive marketplace category explorer; dark Protection process; business feature with original app imagery; Sierra Leone details; FAQ; blue download CTA; footer.

## UX and content
Header anchors, mobile menu, persisted light/dark switch, category tabs, FAQ accordion, real Google Play download links and existing legal/contact destinations. Focus rings, semantic landmarks, skip link, reduced-motion support. English-first with English/Krio support described, no invented Krio translations. NLe. No invented metrics or guarantees.
Approved AI Freetown scene is illustrative, not a customer testimonial. Real app image from existing website. Video generation failed because paid plan required; omit player.

pages/konekta.tsx; app.tsx route composition; styles.css; index.html; public images/fonts/logo. Preserve analytics, providers and Runable runtime plumbing.
